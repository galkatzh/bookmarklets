Bookmarklets

Small tools that live in your bookmarks bar and run on the page you're viewing. Open one to get its install button and instructions.

  • 🌳 ChatGPT Tree Explorer

    Adds a side panel to a ChatGPT conversation that shows every branch created by edits and regenerations. Preview nearby messages, jump between branch endings, and export a branch-aware HTML copy of the whole conversation.

    Works on
    chatgpt.com
    Data
    Stays in your browser; reads the conversation from ChatGPT's own endpoint
    Install →

  • ∑ Gmail LaTeX

    Turns LaTeX in a Gmail draft into equation images. Write formulas between $…$, $$…$$, \(…\) or \[…\] and click the bookmark, or select plain LaTeX to convert only that. You can set a custom preamble.

    Works on
    Gmail compose window
    Data
    Formula source is sent to latex.codecogs.com for rendering
    Install →

  • 🔗 Pick a link, get a summary

    Click the bookmark, then click any link on the page to get a five-bullet summary of where it leads, without opening it. Choose “This page” to summarize the page you're on instead. Press Escape to cancel.

    Works on
    Any web page
    Data
    Page text is sent to ch.at; links to other sites go through Jina Reader. Don't use it on private pages.
    Install →
