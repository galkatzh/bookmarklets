Manual installation and privacy

If drag-and-drop is unavailable, create a bookmark manually and paste the copied URL into its address field. The bookmarklet runs only when you click it. It reads the currently open conversation from ChatGPT’s own authenticated endpoint and does not send it anywhere else.
